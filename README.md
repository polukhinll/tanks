
# Танковый бой

## Описание

Учебный проект на Java.
Реализована пошаговая игра в танки для двух игроков.

## Возможности

- Поле размером 8x8.
- Стены и укрытия.
- Лёгкий и тяжёлый танки.
- Поочерёдные ходы.
- Перемещение и стрельба.
- Повреждения корпуса, башни и гусениц.
- Определение победителя.
- Журнал событий.

## Правила

Каждый игрок управляет одним танком.

За ход можно переместиться в пределах скорости
и выполнить один выстрел либо пропустить стрельбу.

Движение допускается только по горизонтали
или вертикали. Стены и другие танки мешают движению.

Стрелять можно по одной строке или столбцу.
Стены блокируют линию огня.

Укрытия уменьшают получаемый урон на 3.
Броня также уменьшает урон.

Попадание в башню увеличивает урон на 3.
Попадание в гусеницы снижает урон на 2
и уменьшает скорость на 1.

Побеждает игрок, уничтоживший противника.
Если у обоих закончились патроны, объявляется ничья.

## Управление

Формат команды:

dx dy target zone

Примеры:

0 2 -
0 0 H TURRET
-1 0 L HULL

Для пропуска выстрела используется "-".

Для выхода: exit.

## Запуск

Требуется JDK 17 и Maven.

Сборка:
mvn package

Тесты:
mvn test

Запуск:
mvn exec:java -Dexec.mainClass=ru.college.tanks.Main

## Использованные средства

Java 17, Maven, JUnit 5.

## Архитектура

Board - игровое поле.
Position - координаты.
Tank - базовый класс техники.
LightTank - лёгкий танк.
HeavyTank - тяжёлый танк.
Game - правила игры.
GameEvent - событие боя.
Main - консольный интерфейс.

Механика игры не выводит текст в консоль.

## Ограничения

Это учебная упрощённая версия механики.
В игре участвуют два человека.
Диагональная стрельба не реализована.
Боты, турниры и сохранение JSON не добавлены.
